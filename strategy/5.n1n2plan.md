# N1/N2 Expansion Plan

## Goal

현재 `voca_json/VOCA_word_furigana_separated.json` 기준으로 **중복 없이** N1/N2 표현을 확장한다.

핵심 목표는 단순히 어려운 단어 수를 늘리는 것이 아니라, **한국인 학습자가 실제로 자주 틀리거나 헷갈리는 표현**을 우선해서 추가하는 것이다.

## Current Baseline

- Total entries: `1007`
- N2: `346`
- N1: `213`
- Existing normalized-word duplicates: `0`
- Existing same-word duplicates: `0`
- Existing same-reading / same-meaning neighbor groups: `6` 내외

현재 데이터는 N2가 충분히 많은 편이지만, “시험형 N2/N1”보다 “회화형/감각형 N2”가 상대적으로 많다.
따라서 다음 확장은 아래 두 축을 동시에 만족해야 한다.

1. JLPT N1/N2 난도에 맞는 표현일 것
2. 한국인 학습자가 의미/뉘앙스/문형에서 자주 실수할 것

## Hard Constraints

- 현재 있는 표현과 **완전 동일한 표제어는 절대 추가하지 않는다**
- 정규화 기준으로 같은 표현도 추가하지 않는다
  - NFKC 정규화
  - 공백 제거
  - `〜` / `～` 통일
  - 전각/반각 차이 제거
- 현재 표현과 사실상 같은 표현이면 추가하지 않는다
  - 예: 조사만 바뀐 문형
  - 예: 이미 있는 표현의 단순 평서/존댓말 변형
  - 예: 의미 차별화가 안 되는 유의어

## Why Korean Learners Miss These

우선순위는 아래 네 가지 오류 패턴에 둔다.

1. 한자어 형태가 한국어와 비슷해서 “알 것 같지만 실제 의미/용법이 다른 표현”
2. 한국어 한 단어로 번역되지만 일본어에서는 뉘앙스가 갈리는 부사/접속사
3. 문법책에서는 아는데 실제 문장에서 판단이 어려운 N2/N1 문형
4. 한국어 직역 습관 때문에 잘못 쓰기 쉬운 추상 명사/서면어

즉, “외워서 맞히는 단어”보다 “헷갈려서 틀리는 단어”가 우선이다.

## Selection Framework

추가 표현은 아래 6개 버킷으로 채운다.

### 1. False Friends / Hanja Trap

한국어 한자어와 형태가 비슷해 오답 유도가 쉬운 표현.

예:
- `趣旨`
- `見解`
- `根拠`
- `施行`
- `抑制`
- `緩和`

### 2. Similar Adverbs / Connectives

뜻이 비슷해 보이지만 문장 전체 톤이 달라지는 부사.

예:
- `かえって`
- `いっそ`
- `まして`
- `さほど`
- `あくまで`

### 3. Written / Formal Vocabulary

독해와 서면 문맥에서 자주 보지만 회화에서 덜 쓰여 체감 난도가 높은 표현.

예:
- `著しい`
- `おびただしい`
- `ことごとく`
- `免れる`
- `施策`

### 4. High-Frequency N2/N1 Grammar

문형 지식은 있으나, 실제 선택지에서 다른 문형과 자주 충돌하는 표현.

예:
- `ないことはない`
- `ないではいられない`
- `ずにはいられない`
- `にほかならない`
- `に際して`

### 5. Contrastive Pairs

단독 암기보다 세트로 넣어야 효과가 큰 표현.

예:
- `趣旨` vs `主旨`
- `かえって` vs `むしろ`
- `紛らわしい` vs `煩わしい`
- `に伴って` vs `につれて`

### 6. Reading / Register Friction

읽기는 쉬운데 실제 쓰임이 틀리기 쉬운 표현, 또는 회화체와 서면체 간 간극이 큰 표현.

예:
- `もっとも`
- `もっともらしい`
- `かねて`
- `一貫して`

## Batch Plan

한 번에 크게 넣지 않고, 4개 배치로 나눈다.

### Batch A

- Target: `20` expressions
- Focus: N2 중심
- Goal: 한국인이 오답 내기 쉬운 부사/접속사/추상명사

### Batch B

- Target: `20` expressions
- Focus: N1 서면어
- Goal: 독해에서 의미를 잘못 잡기 쉬운 한자어

### Batch C

- Target: `20` expressions
- Focus: N2/N1 문형
- Goal: 선택지형 문제에서 헷갈리는 패턴 보강

### Batch D

- Target: `20` expressions
- Focus: contrast pair
- Goal: 기존 표현과 충돌 없이 “비교 학습” 가능한 세트 완성

권장 총량은 **1차 80개**다.
이 정도가 현재 데이터 규모와 검수 부담 사이에서 가장 현실적이다.

## No-Duplicate Workflow

추가 전에는 반드시 아래 순서로 필터링한다.

1. 표제어 정규화 비교
2. 후리가나 정규화 비교
3. 의미 정규화 비교
4. 이미 있는 표현의 활용형/경어형/평서형 변형인지 확인
5. 기존 항목과 한 세트로 넣어야 의미가 생기는지 확인

추가 금지 예시:

- 이미 있는 표현의 단순 문장 변형
- 이미 있는 표현의 조사 한 글자 변경
- 의미 차별화가 없는 유의어
- 예문만 바꾸면 해결되는 기존 항목의 재등록

### C. High-Value N2/N1 Grammar Candidates

아래는 현재 데이터에 없고, 한국인 학습자에게 교육 효과가 큰 문형 후보다.
문법 레벨은 추가 전 최종 검증이 필요하지만, 우선순위는 매우 높다.

| Expression | Tentative Level | Why It Matters |
|---|---|---|
| ないことはない | N2 | 이중 부정 해석 훈련 |
| ないではいられない | N2 | 감정/충동 문형 구분 |
| ずにはいられない | N2 | 위 표현과 짝으로 넣어야 함 |
| にほかならない | N2~N1 | 서면 단정 표현 |
| をめぐって | N2 | 기사형 문맥 핵심 |
| に際して | N2 | 공문/안내문 빈출 |
| に先立って | N1 | 절차/사전 단계 설명 |
| に照らして | N1 | 기준 비교형 독해 문형 |
| に基づいて | N2 | 정책/보고서 문맥 필수 |
| にかかわる | N2~N1 | 한자어와 결합 시 자주 헷갈림 |

| からすると | N2 | 판단 근거 표현 |

## Recommended Sequence

1. `趣旨 / 主旨 / 概要 / 見解 / 根拠` 세트부터 추가
2. `かえって / いっそ / まして / さほど / あくまで` 부사 세트 추가
3. `紛らわしい / 煩わしい / もっとも / もっともらしい` 혼동 세트 추가
4. `ないことはない / ないではいられない / ずにはいられない / にほかならない` 문형 세트 추가
5. `施行 / 抑制 / 緩和 / 免れる / 著しい / おびただしい` 독해형 어휘 추가

이 순서가 좋은 이유는, “단어 하나”보다 “헷갈리는 축”을 먼저 보강해야 학습 효과가 크기 때문이다.

## Data Fields To Prepare For Each New Entry

각 신규 항목은 아래 기준으로 넣는다.

- `word`
- `furigana`
- `meaning`
- `jlpt`
- `opic`
- `pos`
- `example` 2개
- `synonyms` 3~5개

특히 예문은 아래를 지켜야 한다.

- 직역체 금지
- 한국어 뜻이 한 번에 보이도록 문맥 명확화
- 기존 표현과 헷갈리는 짝이 있으면 예문으로 차이를 드러낼 것

## QA Checklist

추가 후에는 아래를 반드시 돌린다.

1. 현재 데이터와 normalized word 중복 검사
2. 같은 의미 중복 검사
3. 후리가나 자동 보정과 충돌 여부 검사
4. distractor 생성 시 같은 세트끼리 지나치게 충돌하는지 검사
5. `npm run build` 확인
6. Firestore sync 전 `duplicated.md` 재생성

## Decision Rule

추가 대상이 아래 조건 중 2개 이상 만족하면 우선 채택한다.

- 한국어 한자어와 형태가 비슷하지만 용법이 다름
- 기존 데이터에 있는 표현과 비교 학습 축을 만든다
- N1/N2 독해/문형 문제에서 자주 보이는 서면어다
- 한국인 학습자가 직역해서 틀리기 쉽다
- 한 단어 뜻 암기보다 문맥 판단력이 필요하다

## Not Recommended

아래 유형은 이번 N1/N2 확장 1차에서는 제외한다.

- 고유명사
- 지나치게 업계 특화된 명사
- 유행어
- 이미 있는 표현의 존댓말/반말 변형
- 예문 개선으로 해결 가능한 항목
