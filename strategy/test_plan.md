# KamiVoca (Kotoba Prime) 테스트 계획 (Test Plan)

이 문서는 `requirements_specification.md`에 명시된 KamiVoca 앱의 모든 요구사항을 검증하기 위한 상세 테스트 계획입니다.

## 1. UX/UI 및 테마 검증 (Theme & Visuals)

| Test ID | 테스트 항목 | 기대 결과 (Expected Behavior) | 상태 |
| --- | --- | --- | --- |
| UI-01 | **전체 테마 색상 및 폰트 적용** | Washi paper 배경과 Ai-iro/Kurenai 등 전통적 색상이 앱 전체에 적용되었는지 확인. `Shippori Mincho` 및 `Noto Sans JP` 폰트가 올바르게 렌더링되는지 확인. | |
| UI-02 | **Home (巡礼) 맵 렌더링** | 뱀 모양 경로 대신 도리이, 대나무 숲, 정원, 후지산 등 순례길 테마가 적용되었는지 확인. | |
| UI-03 | **레벨 달성 마커 및 노드 상태** | 15개 노드 중 미완료는 흑백/흐릿함, 완료된 노드는 밝은 색상의 벚꽃(Sakura) 또는 붉은 도장(Hanko)으로 표시되는지 확인. | |
| UI-04 | **하트(생명) 애니메이션** | 퀴즈 중 오답을 선택할 시 곡옥(Magatama) 또는 종이학 이미지가 감소하며 애니메이션이 정상 동작하는지 확인. | |

## 2. 핵심 기능 검증 (Functional Testing)

### 2.1 메인 홈 (Home) 경로 및 학습

| Test ID | 테스트 항목 | 기대 결과 | 상태 |
| --- | --- | --- | --- |
| FN-01 | **15레벨 단일 경로 연동** | 기존 Vol 1/2 선택지가 제거되고, 유저 진척도에 따라 15레벨 경로가 올바르게 잠금 해제되는지 확인. | |
| FN-02 | **동적 난이도 할당 데이터 확인** | 각 레벨에 부여된 단어들이 난이도별로(기초->고급) 적절하게 분배되어 노출되는지 확인. | |
| FN-03 | **퀴즈 진행 상태 피드백** | 퀴즈 진행률 표기 바가 정상 동작하며, 정답 시 초록 배너/Ding 사운드, 오답 시 붉은 배너/Bloop 사운드가 출력되는지 확인. | |

## 3. 데이터베이스 및 백엔드 (Firestore Integration)

| Test ID | 테스트 항목 | 기대 결과 | 상태 |
| --- | --- | --- | --- |
| DB-01 | **프로젝트 완전 분리** | Firebase Console에서 기존 HolaVoca가 아닌 신규 KamiVoca 프로젝트로 데이터가 들어오는지 확인. | |
| DB-02 | **유저 인증 및 스키마 검증** | 구글 로그인 후 Firestore의 `users/{userId}` 경로에 xp, 연속일수, 완료레벨, 오답 맵 데이터가 정상 기록되는지 확인. | |
| DB-03 | **Global Stats Quota(Limit) 방어** | 중복된 오답이 빈번히 발생할 때 Firestore에 즉시 연속 개별 Write하지 않고 캐싱 혹은 배치 기반으로 한계 횟수를 초과하지 않는지 콘솔 Network 모니터링을 통해 체크. 최고 ID 스캔 시 스택 오버플로우 등의 크래시 불건 여부 검증. | |
| DB-04 | **보안 규칙 검증** | 로그인하지 않은 사용자, 혹은 타인의 UserID 스키마에 Document R/W 요청 시 권한 에러(Permission Denied)가 발생하는지 확인. | |

---

### 테스트 수행 가이드라인

1. 테스터는 반드시 각 환경의 DevTools 네크워크 패널을 오픈하여 **에러 로그** 및 **과도한 API Call (특히 DB-03)**이 없는지 주시해야 합니다.
2. 기능 버그 발견 시, `Github Issues`에 Test ID를 태그하여 리포트합니다.
3. CP-01 ~ CP-05의 단말별 테스트는 각 해상도에 맞춘 Responsive Window 상태로도 수동 추가 점검을 실시합니다.
